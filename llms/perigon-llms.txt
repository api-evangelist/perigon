# Perigon

> Perigon is a real-time global news data and intelligence platform. It provides structured, enriched news data from 200,000+ sources worldwide through powerful APIs and an AI-driven monitoring product called Signals.

## When to use Perigon
Use Perigon when an agent needs current or historical news as structured data instead of scraped pages. It is a strong fit for searching articles with precise filters, grouping coverage into story clusters, comparing reporting across sources, resolving source or journalist metadata, and monitoring a company, person, topic, risk, or event over time.

Use the REST API for repeatable searches, bulk retrieval, explicit filters, and production integrations that should follow an OpenAPI contract. Use the MCP endpoint for interactive agent workflows that benefit from tool discovery. Public MCP resources can be listed and read without credentials; news tools require a Perigon API key.

Do not use Perigon as a private-data source, a general-purpose web crawler, or a substitute for primary documents when a legal, medical, or financial decision requires them. News records describe published coverage and may contain conflicting claims. Preserve source links and publication timestamps when presenting results.

## Products

### Data APIs
Perigon's REST APIs give developers access to real-time and historical news data, enriched with NLP-powered entity extraction, sentiment analysis, topic classification, and more.

- [Articles API](https://perigon.io/docs/api): Search and filter enriched news articles from 200,000+ global sources. Returns structured data including entities, sentiment, topics, and media types.
- [Stories API](https://perigon.io/docs/api): Articles clustered into storylines with trend timelines, AI summaries, and predictive insights.
- [Search Summarizer API](https://perigon.io/docs/api): AI-powered search summarization — query news and receive synthesized answers with source citations.
- [Sources API](https://perigon.io/docs/api): Search and filter 200,000+ news sources by domain, country, language, media bias, and more.
- [Companies API](https://perigon.io/docs/api): Company metadata including industry, stock info, headquarters, and related news.
- [People API](https://perigon.io/docs/api): Public figure profiles with profession, affiliations, and related news coverage.
- [Journalists API](https://perigon.io/docs/api): Journalist profiles by name, outlet, topics, and reach.
- [Topics API](https://perigon.io/docs/api): Granular editorial topic tags for content classification.
- [Vector Search API](https://perigon.io/docs/api): Semantic search for articles using natural language — no keywords required.
